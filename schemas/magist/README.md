# Magist Schema

This folder contains the SQL schema files used for Magist-related SQL practice challenges.

Magist is an e-commerce database used to practice SQL queries such as joins, aggregations, filtering, subqueries, and business analysis.

## Files

- `magist_schema.sql` — contains the table structure for the Magist database
- `magist_sample_data.sql` — contains a small amount of sample data
- `magist_er_diagram.png` — ER diagram showing the table relationships

## Note

The original Magist database dump file was too large to upload to GitHub.  
To keep this repository clean and easy to review, only the schema structure and small sample data are included.

## Purpose

These files help explain the database structure used in the SQL challenges.  
They allow readers to understand the tables, columns, and relationships behind the queries.
