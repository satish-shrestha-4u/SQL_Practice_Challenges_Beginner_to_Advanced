# IMDB Schema

This folder contains GitHub-friendly IMDB database schema files used for SQL practice challenges.

The original files were large SQL dump files. To keep the repository clean and easy to review, only the table structures and small sample data files are included here.

## Files

- `create_*_table.sql` files contain table structures.
- `sample_*_data.sql` files contain small example rows.
- `imdb_er_diagram.png` — ER diagram
- Full original data dump files are not included because of file size limitations.

## Purpose

These files provide context for the SQL challenges in this repository and help readers understand the tables, columns, and relationships used in the queries.
